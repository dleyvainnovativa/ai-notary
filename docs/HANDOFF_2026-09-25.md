# NotarIA — Handoff (2026-09-25)

Roadmap of 6 phases implemented in one session. This file is the entry point for the next session.

## 1. Install / deploy

```bash
composer require dompdf/dompdf        # PDF preview (pure PHP, works on Hostinger)
```

## Addendum 2026-10-01 — Gratuitous transmissions & nuda propiedad

Tested with deed **498-26464** (donación de nuda propiedad, valor catastral $5,131,600.000, nuda propiedad $2,565,800.00).

- **Forma de pago / instrumento optional** when `tipo_transmision` ∈ {2 herencia, 3 donación, 7 cesión gratuita, 9 servidumbre sin indemnización} (`Modules\AvisosUif\V1\Controller::TRANSMISIONES_GRATUITAS`).
  New generic `formSchema` hint: `'optional_when' => ['^tipo_transmision' => [...]]` — `^` reads the nearest enclosing scope (pago row → its operación). Honored by SchemaEngine (validation, `isRequired`), the PDF ("Falta"), and review.js (asterisk + live validation). A filled-but-invalid value is still flagged.
- **Pagos may be empty** for gratuitous types (no 930017 lines). `valor_pactado` = 0. UIF `postProcess` enforces both as a safety net.
- **UIF prompt** now maps deed language → `tipo_transmision` (it had no rules before; compraventa + hipoteca = 1) and states donantes = vendedores, donatarios = adquirentes.
- **Partial values (UIF `valor_avaluo` and DeclaraNOT `avaluo_inmueble`)**: the AI fills a `valor_calculo` helper (`derecho_transmitido`, `valor_total`, `valor_explicito`, `porcentajes[]`) and never multiplies; `ReferenceResolver` sets the field: explicit amount wins (cross-checked vs total × %; mismatch → amber warning), else total × stacked percentages (rounded to cents), else a warning to capture it. Shown as a note in the form and PDF; the helper never reaches the form/exporter. Config: `module.json → references.partial_values`.
- Applies whenever the deed transmits a partial right, not only for gratuitous types (a sale of nuda propiedad is handled the same way).
- Test: `php tests/manual/GratuitasNudaPropiedadScenarios.php`.
- Still pending: a real OpenAI run on 26464 to confirm the prompt fills `valor_calculo` and `tipo_transmision = 3`.

## Addendum 2026-10-06 — DeclaraNOT por adquisición + concurrency hardening

- Own Controller (extends DeclaraNOT's for person forms, catalogs, nuda-propiedad): no pagos del inmueble / datos informativos; new `monto_operacion` (0 for gratuitous); "ISR por Adquisición" (4 fields) and copropiedad (6 fields). - ⚠ **Open:** the SAT example prints persona **moral** rows with 10 columns (no CURP column) while the structure lists 11. We follow the structure; `Exporter::MORAL_ROWS_WITHOUT_CURP = true` switches to the example's shape. The importer accepts both. Confirm with a file accepted by the SAT portal.

- Test: `php tests/manual/DeclaranotAdquisicionScenarios.php` (uses the SAT example; 34 checks).

**Concurrency (30–50 docs/month: throughput is fine; these are correctness fixes)**
- `config/queue.php` `retry_after` 90 → **480 s** (must exceed the longest job: `ProcessDocumentJob` timeout now **420 s**). Before, a slow job could be handed to a second worker and processed twice.
- OpenAI `request_timeout` 30 → **90 s** + **one retry after 3 s** on transient errors only (timeout, connection, 429, 5xx) — `App\Services\Ai\RetryPolicy`.
- `documents:cleanup` no longer deletes the file of a deed still waiting in the queue; after 24 h (privacy limit) it deletes it, marks the document failed and returns the token.
- Per-user rate limits: uploads/imports/appends 10/min, PDF 20/min, draft saves 60/min.
- Upload / append polling window 3 → 5 min.

**Production cron (Hostinger) — replace the current `queue:work` line:**
```cron
* * * * * cd /home/USER/notaria && php artisan schedule:run >> /dev/null 2>&1
* * * * * cd /home/USER/notaria && php artisan queue:work --stop-when-empty --max-time=50 >> /dev/null 2>&1
```
A plain `queue:work` started every minute never exits → one more worker per minute (they pile up until Hostinger kills them), and deployed code isn't picked up. `--stop-when-empty --max-time=50` makes each run exit; `schedule:run` is required for `tokens:reclaim`, `documents:cleanup` (24 h purge) and `queue:prune-failed`. After deploying, run `php artisan queue:restart` once.
